#Try and Catch

try...catch in JavaScript is used for handling errors without crashing the entire program.
try {
    // code that might cause an error
}
catch (error) {
    // what to do if an error occurs
}

try {
    let x = y;  // y doesn't exist
    console.log(x);
}
catch (error) {
    console.log("Something went wrong!");
}

#setTimeout(function,time)

setTimeout() tells JavaScript:
"Run this function after at least this much time has passed."
setTimeout(function, delay);

setTimeout() doesn't stop the rest of your JavaScript code.
It basically says:
"Hey, run this function later."

# Array Method- forEach(arr)
What is forEach()?
forEach() means:
"Take every element in this array and run this function on it."

const nums = [10, 20, 30, 40];
nums.forEach(x => {
    console.log(x);
});

O/P:-
10
20
30
40

We can also write normal function in it

nums.forEach(function(x){
  console.log(x);
  };

  We can also get the index of items by writing (element, index) as arguments

const fruits = ["apple", "banana", "mango"];
fruits.forEach((fruit, index) => {
    console.log(index, fruit);
});

Output:
0 apple
1 banana
2 mango

You can get the original array too
There are actually three arguments:
array.forEach((element, index, array) => {
    ...
});

For example:
const nums = [10, 20, 30];
nums.forEach((value, index, arr) => {
    console.log(value, index, arr);
});

#Map
The easiest definition:
map() takes every element, transforms it, and returns a new array.
const nums = [1, 2, 3, 4];
const result = nums.map(x => x * 2);
console.log(result);
//[2, 4, 6, 8]
Think:

1 → ×2 → 2
2 → ×2 → 4
3 → ×2 → 6
4 → ×2 → 8

Original: [1, 2, 3, 4]
New:      [2, 4, 6, 8]
map() doesn't change the original,it creates a new array

map() can give you the index
Just like forEach():
const nums = [10, 20, 30];
const result = nums.map((value, index) => {
    return value + index;
});
console.log(result);

Trace:

10 + 0 = 10
20 + 1 = 21
30 + 2 = 32

So:
[10, 21, 32]
The callback can receive:
(element, index, array)

map() with objects 🔥

This is very important for web development.
Suppose you get data like:
const students = [
    {name: "A", marks: 90},
    {name: "B", marks: 80},
    {name: "C", marks: 95}
];

You only want the names:
const names = students.map(student => student.name);
console.log(names);
Output:
["A", "B", "C"]

#Filter

#every()
The definition:
every() checks whether ALL elements satisfy a condition.
And unlike map() and filter(), it returns a boolean:
true / false

Basic example
const nums = [2, 4, 6, 8];
const result = nums.every(x => x % 2 === 0);
console.log(result);

Output:
true
Because every number is even.

Example 2:-
const nums = [2, 4, 7, 8];
const result = nums.every(x => x % 2 === 0);
console.log(result);

Output:
false
Because 7 fails the condition.

#some()
some()

Does AT LEAST ONE element satisfy the condition?
[1, 3, 6].some(x => x % 2 === 0);
→ true
Because 6 is even.

every() with objects
This is useful in real applications.
const students = [
    {name: "A", marks: 80},
    {name: "B", marks: 90},
    {name: "C", marks: 75}
];
const result = students.every(student => student.marks >= 40);
console.log(result);
Output:
true
Everyone passed.

#some
some() asks:
"Does AT LEAST ONE element satisfy this condition?"
It returns a boolean:
true / false

Basic example
const nums = [1, 3, 5, 8, 9];
const result = nums.some(x => x % 2 === 0);
console.log(result);

Output:
true
Why?
Because 8 is even

some() can stop early
Suppose:
const nums = [2, 4, 6, 7, 8, 10];
nums.some(x => x % 2 !== 0);

JavaScript checks:

2 → false
4 → false
6 → false
7 → true ← STOP

It doesn't need to keep checking the rest.
Similarly, every() can stop as soon as it finds a false.
That's why they're called short-circuiting array methods.

#Reduce:-
reduce() takes an entire array and reduces it to ONE final value.

The general syntax
array.reduce((accumulator, currentValue) => {
    return something;
}, initialValue);

For example:
const result = nums.reduce((acc, x) => {
    return acc + x;
}, 0);

Finding the maximum
const nums = [10, 5, 30, 20];
const max = nums.reduce((acc, x) => {
    return Math.max(acc, x);
}, -Infinity);
console.log(max);

reduce() can build objects 🔥

This is where it becomes really powerful.

Suppose:

const nums = [1, 2, 3, 2, 1, 2];

We want to count frequencies.
const freq = nums.reduce((acc, x) => {
    acc[x] = (acc[x] || 0) + 1;
    return acc;
}, {});
console.log(freq);
Result:
{
    1: 2,
    2: 3,
    3: 1
}
Here the accumulator isn't a number anymore.
It's an object

So reduce() can reduce an array into:

number
string
object
array
etc.

Absolutely. This is a small but **very useful function feature** in JS.

## Default parameters
A **default parameter** is a value JavaScript uses when you **don't provide an argument**.

### Without a default
function greet(name) {
    console.log("Hello " + name);
}

greet("Shourya");
Output:
Hello Shourya
But:
greet();
Output:
Hello undefined
Because `name` wasn't given a value.

## With a default parameter

function greet(name = "Guest") {
    console.log("Hello " + name);
}
Now:
greet("Shourya");
Hello Shourya
But:
greet();
→
Hello Guest
So:
function greet(name = "Guest")
means:
> If the caller doesn't provide `name`, use `"Guest"`.

---

## 🏹 Works with arrow functions too

const greet = (name = "Guest") => {
    console.log("Hello " + name);
};

## Multiple parameters

You can have several defaults:
function calculate(a = 10, b = 5) {
    return a + b;
}

#... = Spread
The basic idea:
Spread takes the elements inside an array/object and "spreads" them out.
Spread with arrays
Suppose:
const nums = [1, 2, 3];
Normally:
console.log(nums);
gives:
[1, 2, 3]
But:
console.log(...nums);
gives:
1 2 3
It's basically:
console.log(1, 2, 3);
So:
...nums
means:
"Take everything inside nums and spread it here."

Combining arrays 🔥
This is one of the most common uses.
const a = [1, 2, 3];
const b = [4, 5, 6];\
const c = [...a, ...b];
console.log(c);

Output:
[1, 2, 3, 4, 5, 6]
Adding elements to an existing array
const nums = [2, 3, 4];
const result = [1, ...nums, 5];
console.log(result);
Output:
[1, 2, 3, 4, 5]

Copying an array
Very useful:

const nums = [1, 2, 3];
const copy = [...nums];
console.log(copy);

Now:
nums → [1, 2, 3]
copy → [1, 2, 3]
But they're separate arrays.

Spread with objects 🔥

Spread isn't only for arrays.
const person = {
    name: "Shourya",
    age: 19
};
const copy = {
    ...person
};
