#Map
The easiest definition:
map() takes every element, transforms it, and returns a new array.
const nums = [1, 2, 3, 4];
const result = nums.map(x => x * 2);
console.log(result);
//[2, 4, 6, 8]
Think:

1 → ×2 → 2
2 → ×2 → 4
3 → ×2 → 6
4 → ×2 → 8

Original: [1, 2, 3, 4]
New:      [2, 4, 6, 8]
map() doesn't change the original,it creates a new array

map() can give you the index
Just like forEach():
const nums = [10, 20, 30];
const result = nums.map((value, index) => {
    return value + index;
});
console.log(result);

Trace:

10 + 0 = 10
20 + 1 = 21
30 + 2 = 32

So:
[10, 21, 32]
The callback can receive:
(element, index, array)

#every()
The definition:
every() checks whether ALL elements satisfy a condition.
And unlike map() and filter(), it returns a boolean:
true / false

Basic example
const nums = [2, 4, 6, 8];
const result = nums.every(x => x % 2 === 0);
console.log(result);

Output:
true
Because every number is even.

Example 2:-
const nums = [2, 4, 7, 8];
const result = nums.every(x => x % 2 === 0);
console.log(result);

Output:
false
Because 7 fails the condition.

#some()
some()

Does AT LEAST ONE element satisfy the condition?
[1, 3, 6].some(x => x % 2 === 0);
→ true
Because 6 is even.

every() with objects
This is useful in real applications.
const students = [
    {name: "A", marks: 80},
    {name: "B", marks: 90},
    {name: "C", marks: 75}
];
const result = students.every(student => student.marks >= 40);
console.log(result);

true
Everyone passed.

#some
some() asks:
"Does AT LEAST ONE element satisfy this condition?"
It returns a boolean:
true / false

Basic example
const nums = [1, 3, 5, 8, 9];
const result = nums.some(x => x % 2 === 0);
console.log(result);

Output:
true
Why?
Because 8 is even

some() can stop early
Suppose:
const nums = [2, 4, 6, 7, 8, 10];
nums.some(x => x % 2 !== 0);

JavaScript checks:

2 → false
4 → false
6 → false
7 → true ← STOP

It doesn't need to keep checking the rest.
Similarly, every() can stop as soon as it finds a false.
That's why they're called short-circuiting array methods.

#Reduce:-
reduce() takes an entire array and reduces it to ONE final value.

The general syntax
array.reduce((accumulator, currentValue) => {
    return something;
}, initialValue);

For example:
const result = nums.reduce((acc, x) => {
    return acc + x;
}, 0);

Finding the maximum
const nums = [10, 5, 30, 20];
const max = nums.reduce((acc, x) => {
    return Math.max(acc, x);
}, -Infinity);
console.log(max);

reduce() can build objects 🔥

This is where it becomes really powerful.

Suppose:

const nums = [1, 2, 3, 2, 1, 2];

We want to count frequencies.
const freq = nums.reduce((acc, x) => {
    acc[x] = (acc[x] || 0) + 1;
    return acc;
}, {});
console.log(freq);
Result:
{
    1: 2,
    2: 3,
    3: 1
}
Here the accumulator isn't a number anymore.
It's an object

So reduce() can reduce an array into:

number
string
object
array
etc.

## Default parameters
A **default parameter** is a value JavaScript uses when you **don't provide an argument**.

### Without a default
function greet(name) {
    console.log("Hello " + name);
}

greet("Shourya");
Output:
Hello Shourya
But:
greet();
Output:
Hello undefined
Because `name` wasn't given a value.

## With a default parameter

function greet(name = "Guest") {
    console.log("Hello " + name);
}
Now:
greet("Shourya");
Hello Shourya
But:
greet();
→
Hello Guest
So:
function greet(name = "Guest")
means:
> If the caller doesn't provide `name`, use `"Guest"`.

---

## 🏹 Works with arrow functions too

const greet = (name = "Guest") => {
    console.log("Hello " + name);
};

## Multiple parameters

You can have several defaults:
function calculate(a = 10, b = 5) {
    return a + b;
}

#... = Spread
The basic idea:
Spread takes the elements inside an array/object and "spreads" them out.
Spread with arrays
Suppose:
const nums = [1, 2, 3];
Normally:
console.log(nums);
gives:
[1, 2, 3]
But:
console.log(...nums);
gives:
1 2 3
It's basically:
console.log(1, 2, 3);
So:
...nums
means:
"Take everything inside nums and spread it here."

Combining arrays 🔥
This is one of the most common uses.
const a = [1, 2, 3];
const b = [4, 5, 6];\
const c = [...a, ...b];
console.log(c);

Output:
[1, 2, 3, 4, 5, 6]
Adding elements to an existing array
const nums = [2, 3, 4];
const result = [1, ...nums, 5];
console.log(result);
Output:
[1, 2, 3, 4, 5]

Copying an array
Very useful:

const nums = [1, 2, 3];
const copy = [...nums];
console.log(copy);

Now:
nums → [1, 2, 3]
copy → [1, 2, 3]
But they're separate arrays.

Spread with objects 🔥

Spread isn't only for arrays.
const person = {
    name: "Shourya",
    age: 19
};
const copy = {
    ...person
};

##DOM
DOM — Document Object Model

DOM (Document Object Model) is a programming interface that represents an HTML document as a tree of objects/nodes.
In simple words:
HTML → Browser creates DOM → JavaScript can access and modify it
Example HTML
<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1>Hello</h1>
    <p>This is a paragraph.</p>
    <button>Click Me</button>
</body>
</html>

The browser converts this into a DOM tree:
Document
   |
  html
 /    \
head   body
 |     / | \
title h1 p button
Each HTML element becomes a DOM node/object.
The DOM gives JavaScript access to the webpage so we can:
Change HTML content
Change CSS/styles
Change attributes
Add elements
Remove elements
Respond to user actions/events
document

##Selecting Elements:-
There are several ways to select elements.

1. getElementById()

Selects one element using its id.

HTML
<h1 id="heading">Hello</h1>
JavaScript
let heading = document.getElementById("heading");
console.log(heading);

Notice:
document.getElementById("heading")
We don't use # here.

2. getElementsByClassName()
Selects all elements having a particular class.
<p class="para">One</p>
<p class="para">Two</p>
<p class="para">Three</p>
let paragraphs = document.getElementsByClassName("para");
console.log(paragraphs);

It returns an HTMLCollection.
You can access individual elements using an index:
console.log(paragraphs[0]);
console.log(paragraphs[1]);

3. getElementsByTagName()
Selects elements based on their HTML tag.
let paragraphs = document.getElementsByTagName("p");
This selects all <p> elements.
Similarly:
let headings = document.getElementsByTagName("h1");

4. querySelector() ⭐
This is one of the most important methods.
It selects the first element matching a CSS selector.

By ID
document.querySelector("#heading");
By class
document.querySelector(".para");
By tag
document.querySelector("p");
More complex selector
document.querySelector("div p");

So querySelector() follows CSS selector syntax.

5. querySelectorAll() ⭐
Selects all elements matching a CSS selector.
let paragraphs = document.querySelectorAll(".para");
It returns a NodeList.
You can access elements:
console.log(paragraphs[0]);

And you can use:
paragraphs.forEach((p) => {
    console.log(p);
});
Quick comparison
Method	Selects	Returns
getElementById()	One ID	Element
getElementsByClassName()	All matching classes	HTMLCollection
getElementsByTagName()	All matching tags	HTMLCollection
querySelector()	First matching CSS selector	Element
querySelectorAll()	All matching CSS selectors	NodeList

Changing HTML Content 🚀
Once we select an element, we can change its content using JavaScript.

There are 3 important properties:
1. textContent ⭐
Gets or changes the text inside an element.
<h1 id="heading">Hello</h1>
let heading = document.querySelector("#heading");
heading.textContent = "Hello Shourya!";

Now the webpage shows:
Hello Shourya!
It treats everything as text
heading.textContent = "<b>Hello</b>";

The browser displays:
<b>Hello</b>

2. innerHTML ⭐
Gets or changes the HTML inside an element.
heading.innerHTML = "<b>Hello Shourya!</b>";
Now Hello Shourya! becomes bold because <b> is interpreted as HTML.
You can also add multiple elements:
let div = document.querySelector("div");
div.innerHTML = `
    <h2>Hello</h2>
    <p>Welcome!</p>
`;
3. innerText
Gets or changes the visible text of an element.
heading.innerText = "Hello!";

Adding Elements to the DOM ➕
Now we move to one of the most useful DOM operations:
Creating a new HTML element using JavaScript and adding it to the webpage.
There are mainly 3 steps:
Create → Add content → Attach to DOM
1. createElement() ⭐
Creates a new HTML element.
let p = document.createElement("p");
This creates:
<p></p>
But ⚠️ it is not yet visible on the webpage.
It's only created in memory.

2. Add content
We can use textContent:
p.textContent = "Hello Shourya!";
Now our element is:
<p>Hello Shourya!</p>

Suppose we want to create:
<div>
    <p>Hello Shourya</p>
    Welcome!
</div>
Step 1: Create the elements
let div = document.createElement("div");
let p = document.createElement("p");
Step 2: Add content to <p> using appendChild()
appendChild() requires a Node, so we create a text node:
let text = document.createTextNode("Hello Shourya");
p.appendChild(text);
Now:
<p>Hello Shourya</p>
Step 3: Add <p> into <div>
div.appendChild(p);
Now:
<div>
    <p>Hello Shourya</p>
</div>
Step 4: Add additional text using append()
div.append("Welcome!");

Now the final structure is:
<div>
    <p>Hello Shourya</p>
    Welcome!
</div>
⭐ Why this demonstrates the difference
p.appendChild(text);
appendChild() → accepts a Node
div.append("Welcome!");
append() → can accept text directly and can also accept elements/nodes.
You could actually do:
p.append("Hello Shourya");
without creating a text node.
So:
appendChild() → Node only
append()      → Node + text

prepend()
Adds the element at the beginning.
container.prepend(p);
If we have:
<div>
    <h1>Heading</h1>
    <p>Existing paragraph</p>
</div>

After:
container.prepend(p);
the new paragraph becomes the first child.

##JavaScript gives us a few ways to remove elements from the DOM.

1. remove() ⭐
The simplest method.
<div id="box">
    <p>Hello</p>
</div>
let box = document.querySelector("#box");
box.remove();
The entire <div> is removed from the page.

2. removeChild() ⭐
Used when you want the parent to remove one of its children.
let box = document.querySelector("#box");
let p = document.querySelector("p");
box.removeChild(p);

Before:
<div id="box">
    <p>Hello</p>
</div>

After:
<div id="box"></div>
The syntax is:
parent.removeChild(child);
